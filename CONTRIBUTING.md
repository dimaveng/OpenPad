# Contributing / Участие

English: Open an issue describing the problem and reproduction steps. For code changes, branch from `main`, keep changes focused, run the audio and UI smoke tests described in the README, and open a pull request. Contributions to this repository are submitted under GPL-3.0-only. Do not commit audio you do not have permission to distribute, personal `Data` folders, or credentials.

Русский: создайте issue с описанием проблемы и шагами воспроизведения. Для изменения кода создайте ветку от `main`, выполните аудиотесты и UI-проверки из README, затем откройте pull request. Вклад в этот репозиторий предоставляется под GPL-3.0-only. Не добавляйте чужое аудио без права распространения, личные папки `Data` или секреты.
