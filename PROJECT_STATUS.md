# OpenPad — состояние проекта

Дата проверки: 17 ноября 2026 года. Завершён этап 1: инвентаризация и сохранение состояния. Следующий этап требует подтверждения пользователя.

## Что это за проект

OpenPad — саундпад для Windows на C# / .NET 10 / WPF. Воспроизводит клипы и смешивает их с физическим микрофоном. Через VB-CABLE смесь поступает в Discord. Есть Ogg Vorbis / Opus, усиление до 500%, Bass Boost и отдельная громкость голоса. Код и интерфейс созданы с помощью OpenAI Codex по требованиям dimaveng.

## Правила дальнейшей работы

Перед крупными изменениями: отдельная ветка и сохранение рабочей версии. После каждого этапа — отчёт и ожидание подтверждения. При редизайне аудиодвижок не менять без необходимости. В конце этапа записывать выполненное и точку продолжения; точный остаток лимитов агенту недоступен.

WPF-скилл прочитан. Его основные рекомендации — MVVM, команды и привязки, словари ресурсов, шаблоны данных, асинхронный ввод/вывод и виртуализация списков. В нём есть иллюстративные фрагменты, которые нельзя копировать без проверки применимости к WPF. Архитектурный рефакторинг не входит в этап 1.
