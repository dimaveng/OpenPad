OpenPad Portable — Windows x64

ENGLISH
Extract the entire ZIP into a writable folder and run OpenPad.exe. .NET is included.
Newly imported sounds are copied into Data/Sounds; OPL imports go into Data/Imports.
Settings and the library stay in Data. Close OpenPad before moving the whole folder.
Use Updates in the sidebar to update this copy while keeping Data.
To bring a library from the installed edition, export an .opl and import it here.
VB-CABLE is a SYSTEM DRIVER, not a portable component. It must be installed once
on each computer to mix your microphone and sounds into Discord. Open VB-CABLE.url
or https://vb-audio.com/Cable/ and follow the publisher's driver instructions.
In Discord choose CABLE Output as input; in OpenPad choose CABLE Input as output.
Without VB-CABLE you can still play sounds through normal speakers/headphones.

УКРАЇНСЬКА
Розпакуй весь ZIP у папку з правом запису та запусти OpenPad.exe. .NET уже всередині.
Нові звуки копіюються до Data/Sounds, імпортовані .opl — до Data/Imports.
Бібліотека й налаштування зберігаються в Data. Перед перенесенням усієї папки закрий
OpenPad. Оновлення доступні в бічній панелі. Стару бібліотеку перенеси через .opl.
VB-CABLE — системний драйвер: для Discord його треба встановити один раз на кожному
комп'ютері. Відкрий VB-CABLE.url. У Discord вибери CABLE Output, у OpenPad — CABLE Input.

РУССКИЙ
Распакуй весь ZIP в папку с правом записи и запусти OpenPad.exe. .NET уже внутри.
Новые звуки копируются в Data/Sounds, импортированные .opl — в Data/Imports.
Библиотека и настройки хранятся в Data. Перед переносом всей папки закрой OpenPad.
Обновления доступны в боковой панели. Старую библиотеку перенеси через .opl.
VB-CABLE — системный драйвер: для Discord его нужно установить один раз на каждом
компьютере. Открой VB-CABLE.url. В Discord выбери CABLE Output, в OpenPad — CABLE Input.
